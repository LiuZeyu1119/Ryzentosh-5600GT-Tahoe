# Ryzen 5 5600GT Tahoe OpenCore 引导

这是一份以 `nickolasdeluca/Ryzentosh-5600GT` 配置为基础、补齐真实二进制后的首启/安装版 EFI。

## 目标硬件

- AMD Ryzen 5 5600GT（Zen 3 / Cezanne，6 核 12 线程）
- 使用 5600GT 自带 Vega 核显
- Realtek RTL8111/RTL8168 有线网卡
- macOS Tahoe

声卡、Wi-Fi、蓝牙和主板 USB 端口映射因硬件未知，没有盲目添加。

## 主板配置选择

当前 `EFI/OC/config.plist` 与 `Profiles/B450-X470-X570/config.plist` 相同：

- B450、X470、X570 或其他不需要 `SSDT-CPUR` 的 AM4 主板可先直接测试。
- 某些使用较新 BIOS 的 B450/X470 也可能需要将 `Booter -> Quirks -> SetupVirtualMap` 改为 `false`。

如果主板是 B550 或 A520：

1. 备份 `EFI/OC/config.plist`。
2. 用 `Profiles/B550-A520/config.plist` 替换 `EFI/OC/config.plist`。
3. 该配置已经启用 `SSDT-CPUR.aml`，并关闭 `SetupVirtualMap`。

不要在非 B550/A520 主板上启用 `SSDT-CPUR.aml`。

## BIOS 首启设置

- 关闭 Secure Boot、CSM/Legacy Boot、Fast Boot。
- 开启 Above 4G Decoding、XHCI Hand-off。
- SATA 设置为 AHCI。
- UMA Frame Buffer 设置为 2 GB，最低不要小于 1 GB。
- 首次测试建议关闭 Resizable BAR；如果必须开启，需要同时核对 `ResizeAppleGpuBars`。
- 从 UEFI 启动项启动，入口文件是 `EFI/BOOT/BOOTx64.efi`。

## 已做的关键处理

- OpenCore 1.0.7 RELEASE，驱动与 OpenCore 同版本。
- AMD_Vanilla 补丁覆盖到 Darwin 25，四个核心数补丁均设为十六进制 `06`。
- 启用 NootedRed；没有加入 WhateverGreen 或 NootRX。
- 启用 Lilu、VirtualSMC、AppleMCEReporterDisabler、RealtekRTL8111、RestrictEvents。
- 使用通用桌面 `SSDT-EC-USBX-DESKTOP.aml`。
- 删除参考仓库中依赖未知主板的 USB-Reset、XOSI 和固定网卡 PCI 路径。
- 未套用他人的 UTBMap。当前临时启用 `XhciPortLimit`，安装完成后应制作本机 USB 映射并关闭它。
- 已生成仅供本机使用的 MacPro7,1 SMBIOS。不要公开或复制给其他机器。
- 首启保留 `-v keepsyms=1 debug=0x100`，稳定后可以清空 `boot-args`。

## 使用方式

1. 先备份现有 EFI。
2. 根据主板选择配置文件。
3. 把本目录内的 `EFI` 文件夹复制到 FAT32 EFI 分区根目录。
4. 首次成功进入 OpenCore 后按空格显示辅助项，并执行一次 Reset NVRAM。
5. 启动 Tahoe 安装器。如果失败，保存屏幕最后几行和 `EFI/OC/Logs` 中的日志。

## 仍需按硬件完成

- 用 USBToolBox 为本机主板和机箱接口制作 UTBMap。
- 按声卡 codec 添加 AppleALC 及正确的 `alcid`。
- 按实际 Wi-Fi/蓝牙芯片添加对应驱动。
- 如果有独立显卡，需单独判断是否受 macOS 支持，并确认是否需要在 macOS 中屏蔽。
- 确认实际有线网卡确为 RTL8111/RTL8168；如果不是，应替换网卡 kext。
